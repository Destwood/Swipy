# Screenshots to capture

Save the files in this folder with exactly these names (PNG, ~1440px wide):

| File | What to show |
| --- | --- |
| `deck.png` | The swipe deck mid-session: a game card with the like / skip controls and the game info sidebar visible. |
| `lobby.png` | A friend session lobby with at least 2–3 members listed and the session code / invite link visible. |
| `matches.png` | The shared matches view after a session: games grouped by agreement (100% / 75% / 50% match) with voter avatars. |

The main README references these three files.
